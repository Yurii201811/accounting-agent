# Human review checklist

- [ ] The entity, jurisdiction, currency, period, and version are correct.
- [ ] Every material input has a source, as-of date, and owner.
- [ ] Key totals reconcile to the approved source of truth.
- [ ] Formulas and deterministic calculations were inspected, not inferred from prose.
- [ ] Assumptions, estimates, confidence limits, and missing information are visible.
- [ ] Possible duplicates, unknown suppliers, changed bank details, and uncertain VAT are blocked.
- [ ] Personal or confidential data stayed inside an approved environment.
- [ ] The agent did not approve its own work or broaden its permissions.
- [ ] External communication, filing, posting, payment, deletion, and settings changes remain with an authorized human.
- [ ] The change log or before/after diff is retained with the review decision.
