# Changelog

All notable changes to Accounting Agent are documented here. The project uses
semantic versioning for its public Python and CLI compatibility contract.

## Unreleased

### Added

- Apache-2.0 licensing, contribution, governance, conduct, security, DCO, and
  repository ownership policies.
- Durable public-core/private-cloud, provenance, privacy, and release-gate
  contracts.
- Contract tests for governance files, package inclusion, and publishable
  source provenance.
- Immutable tenant/archive, canonical accounting, read-only sync/reconciliation,
  approval/draft, and model-route production contracts without external
  authority.
- Cross-language restricted-JSON SHA-256 vectors and additive traceability for
  all 207 public Python exports while preserving the original v1 surface.

## 1.0.0

- Established the v1 public Python surface and nine-command CLI.
- Added deterministic, synthetic-only accounting preparation and QA flows.
